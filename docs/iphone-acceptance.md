# iPhoneでの確認（実画像は添付しない）

対象版: アプリの「おうちの方へ」のバージョンを記録。公開後はSafariでページを再読込。すでにPWAを入れている場合、アプリと同じページのタブをすべて閉じ、開き直す。

明るい場所、6:00〜20:59、お顔を正面に映して確認してください。21時以降は翌日で構いません。夜間制限を解除するために端末時刻を変更する必要はありません。

## 1.1の見た目と触り心地

「おうちの方へ」で `1.1.0` と表示される版で、次を確認してください。

1. 最初の画面の3匹をなでると、それぞれ違う返事。ここではカメラはまだ起動しない。
2. どの子も耳やしっぽまで表示され、選ぶボタンが押しやすい。
3. 数秒目を閉じてから開けると、びっくり顔と紙のフレームの写真。残り時間を保って再開できる。
4. 木・おうち・おはなを直接タップ。見つけると喜び、おはなが1つ咲く。見つけた子もなでられる。
5. もう1回見つけるとおはなが2つ。カウント達成後も目を閉じている間は静かなまま。
6. iPhoneの「視差効果を減らす」が有効なら、揺れや跳ねる動きが止まる。

新しい見た目の実機確認は未確認。以下の基本機能のうち、PR #16 / `7ea5812` ではカメラ・選択／開眼写真／残り再開／開眼維持／顔喪失と復帰／達成後探索／発見から15秒／タブ復帰の8項目をユーザーが確認済み（[ロードマップの実機報告](https://github.com/ishiishikou/mi-tsuketa/issues/1#issuecomment-6232847168)）。新しい版で再確認するときは下の表を使えます。
